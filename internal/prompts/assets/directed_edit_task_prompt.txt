Apply the author's instructions to the line-numbered document below and return up to {{.BatchSize}} non-overlapping edits.

Rules for each edit:
- target_line: 1-based line number where the edit begins (from the `N| ` prefix; never include `N| ` in old_text or new_text).
- action: "replace" to substitute text, "delete" to remove text/line/paragraph, or "insert_after" to add text immediately after old_text.
- old_text: exact character-for-character substring from the document (without line-number prefixes).
- new_text: replacement text (for "replace"), text to insert (for "insert_after"), or "" (for "delete").
- reason: short explanation linking the change to the author's instructions.
- Only include changes required by the instructions. Do not overlap edits.
- Set more_rounds_needed to true only if additional batches are still required to finish the task.
- If the task is already complete, return an empty edits array and more_rounds_needed=false.
